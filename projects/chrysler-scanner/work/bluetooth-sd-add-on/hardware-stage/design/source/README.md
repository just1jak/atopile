Copy this source directory to a fresh scratch location. Run generate_design.py with Python3.10+ and sexpdata, then build_board.py using KiCad10 bundled Python/pcbnew. Run finalize.py with sexpdata available, then regenerate schematic.png from schematic.pdf. All generated content is written into a new design/ subdirectory. The scripts never write the scanner project. Generator paths for native installed KiCad libraries are explicit macOS defaults; adjust them for another installation. Do not regenerate over a manually edited carrier.
